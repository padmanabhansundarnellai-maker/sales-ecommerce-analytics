# Sales E-Commerce Analytics

**Problem:** Analyze sales, profit, customers, and regional performance to identify business trends.

**Dataset:** Sample Superstore dataset, 9,994 rows.

**What I did:**

* Cleaned and analyzed sales data using Python and Pandas
* Calculated revenue, profit, average order value, and repeat customers
* Wrote SQL queries in MySQL for business analysis
* Prepared the project for Power BI dashboard development

**Key Findings:**

* Revenue: 1,307,032
* Profit: 239,100
* Average Order Value: 260.94
* Repeat Customers: 98.5%

**Files:**

* `1_sales_analysis_py.py` — Python analysis
* `1_sales_queries.sql` — SQL analysis
* `dashboard.png` — Power BI dashboard (to be added later)
